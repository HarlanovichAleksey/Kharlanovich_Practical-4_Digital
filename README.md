# Практическая работа №4 — Digital Marketing Agency

**Автор:** Харланович Алексей, ПИУКИС-23

## Описание
Свёрстан адаптивный лендинг по макету **Digital Marketing Agency**.
Вёрстка подогнана под макет через расширение **Perfect Pixel**.

## Что реализовано
- **Hero-секция** — заголовок, текст, кнопка призыва к действию с градиентным фоном;
- **Секция `Our Services`** — три карточки с SVG-иконками (`img1.svg`, `img2.svg`, `img3.svg`);
- **Секция `Our Talented Member`** — три горизонтальные карточки с аватарками;
- **Нативные CSS-анимации кнопок** — выезжающий фон через `::before`, hover с тенью;
- **Библиотечные анимации** — Animate.css + WOW.js (появление текста и карточек при скролле);
- **Hover-эффекты карточек** — сдвиг, увеличение иконок, drop-shadow, поворот аватарок;
- **Адаптив** для планшетов и мобильных (1200px / 992px / 620px).

## Технологии
- HTML5
- CSS3 (Flexbox, transitions, псевдоэлементы, градиенты)
- Animate.css 4.1.1
- WOW.js 1.1.2
- Google Fonts (Montserrat)

## Файлы
- `index.html` — разметка страницы;
- `css/style.css` — стили и адаптив;
- `img/` — SVG-иконки услуг и аватарки команды.
