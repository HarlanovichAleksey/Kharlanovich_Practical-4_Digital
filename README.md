# Практическая работа №4 — адаптивный лендинг Digital Marketing Agency

**Автор:** Харланович Алексей, ПИУКИС-23

## Описание
Свёрстан адаптивный лендинг по макету **Digital Marketing Agency**.
Реализованы:
- шапка (hero-секция) с заголовком, текстом и кнопкой призыва к действию;
- секция услуг `Our Services` из трёх карточек;
- иконки для карточек услуг подключены через **Font Awesome 6**;
- адаптивная вёрстка под планшеты и мобильные устройства через `@media`;
- шрифт **Montserrat**, подключённый через Google Fonts.

## Технологии
- HTML5
- CSS3 (Grid, Flexbox, медиа-запросы)
- Font Awesome 6 (CDN)
- Google Fonts (Montserrat)

## Контрольные точки адаптива
- **> 992px** — 3 карточки услуг в ряд;
- **768px–992px** — 2 карточки в ряд;
- **< 768px** — 1 карточка в ряд, уменьшенные отступы;
- **< 420px** — уменьшенный размер заголовка.
